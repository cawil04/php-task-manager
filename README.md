# PHP Task Manager

## Project Description
PHP Task Manager is a simple web application for managing daily tasks.

## Features
- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- View task descriptions and due dates

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Database
Database name: `task_manager`

Table name: `tasks`

## How to Run
1. Install XAMPP.
2. Start Apache and MySQL.
3. Create the `task_manager` database using phpMyAdmin.
4. Set up the required `tasks` table.
5. Open `http://localhost/taskManager.php` in your browser.
